# Engineering Science A: Revision Website

**[▶ Open the website](https://freddysalem.github.io/eng-sci-revision/)**

A self-contained revision web app for the University of Bristol **Engineering Science A** unit
(mechanics, structures, electrical). I built it to revise for my own exams (84% in the unit), and
classmates asked for access.

- **Today:** a daily study plan that reschedules itself if you fall behind, with a Pomodoro timer and notes.
- **Resources:** topic-by-topic notes and explainer videos for all three modules, with progress tracking.
- **Formula Books:** equation sheets for Mechanics, Electrical and Structures.
- **Test → Review → Play:** tests and a review of every answer, plus
  **[Eng Sci Invasion](https://github.com/freddysalem/eng-sci-invasion)**, the comet-defence game
  built into the Play tab and set up from today's plan.

One HTML file with no install. Progress is saved in your own browser.
